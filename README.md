# Cookie Clicker AI Bot

Высокопроизводительный бот для автоматизации игры Cookie Clicker, использующий кастомную нейросеть YOLOv8. Главная особенность проекта — полный отказ от тяжеловесного PyTorch в пользу **OpenCV DNN** и формата **ONNX**, что сделало запуск молниеносным и снизило размер зависимостей с 3 ГБ до ~150 МБ.

## ✨ Ключевые возможности

*   **🍪 Клик по печенью**: Мгновенное распознавание и клик по основной цели.
*   **🛒 Умная покупка улучшений**: Вместо хаотичных кликов бот делает "свайп" снизу вверх по панели улучшений. Настроен сдвиг по оси X, чтобы случайно не переключить режим покупки на "Купить 10".
*   **🚫 Закрытие рекламы**: Модель обучена распознавать класс `reclamd` и автоматически закрывать всплывающие баннеры.
*   **⚡ Ультра-легкий инференс**: Благодаря `cv2.dnn` и ONNX, скрипту не нужны `ultralytics` и `torch`. Запуск занимает доли секунды.
*   **🛑 Безопасная остановка**: Остановка по нажатию клавиши `Пробел` или при уводе мыши в левый верхний угол (Fail-Safe).
*   **⚙️ Гибкая конфигурация**: Все задержки, пороги уверенности и отступы вынесены в словарь `CONFIG` в начале скрипта.
